# **App Name**: Sistema Evaluador Educativo - Chubut

## Core Features:

- Gestión de Exámenes: Creación de exámenes con preguntas, respuestas correctas y puntajes asignados (1, 0.5, 0) por Evaluador o Referente.
- Carga de Resultados por Docente: Carga de puntajes por docente para cada respuesta de cada alumno en un formulario por examen (puntajes: 0, 0.5, 1).
- Generación de Fichas de Resultados: Generación automática de fichas de resultados individuales por alumno con su grado, curso, escuela y distrito.
- Bases de Datos Inmutables: Almacenamiento de datos en bases de datos inmutables una vez cerradas para garantizar la integridad de la información.
- Análisis de Resultados con Gráficos: Visualización de análisis de resultados de las evaluaciones con gráficos de línea, incluyendo promedios, comparaciones, aprobados/desaprobados, y análisis por pregunta.
- Exportación de Resultados: Extracción del análisis en formatos CSV o Excel para su impresión o uso en otras herramientas.
- Gestión de Usuarios: Gestión de usuarios con diferentes roles: Evaluador, Referente, Administrador, Director, Docente, cada uno con permisos específicos.
- Filtros de Análisis: Implementación de filtros por distrito, escuela, grado, curso, examen o combinación de estos para análisis específicos.

## Style Guidelines:

- Colores preferidos: rojo, naranja, amarillo, combinados de forma armónica para un diseño moderno y atractivo.
- Diseño moderno y fácil de usar, responsive para su uso en celulares, tablets y computadoras.
- Tipografía legible y amigable para facilitar la lectura y comprensión de la información.
- Formularios claros con campos bien organizados para una carga de datos eficiente.
